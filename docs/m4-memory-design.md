# 小辽 M4「回忆与传承」功能设计文档（草稿）

> 状态：设计讨论整理稿，待评审
> 关联项目：小辽 — 老年积极心理AI助手（xiaoliao-elderly-agent）

## 1. 背景与定位

- 小辽现有能力：M2 认知训练游戏、M3 积极心理练习（三件好事/感恩留言/成就墙/每周小结）、每日打卡、AI 对话（Python AI 引擎 + 企微/小程序）。
- 本模块定位：**回忆疗法 + 传承感**。让老人用最舒服的方式（语音优先）回顾一生，产出照片与故事，沉淀为以老人自己为主线的时光轴，并形成可分享给家人的传承物。
- 心理依据：回忆疗法对老年情绪与幸福感有实证价值；传承感满足老人"被需要"的心理需求，与 M3"多鼓励少惩罚"的产品调性一致。

## 2. 总体设计：一个闭环，两个功能

- **年代相册 = 内容生产入口**：老人拍"现在"的照片，口述"以前是什么样子"，按描述配"过去模样"的示意图，产出今昔对比故事与朋友圈文案。
- **人生时光轴 = 内容沉淀结构**：以老人自己的一生为主线，家人事件作为挂载节点。
- **终极产物 = 传承物**：朋友圈图文卡片 / 家书 / 人生长图。
- 闭环：相册讲故事 → 时间轴沉淀 → 传承物分享 → 家人点赞反馈 → 老人继续讲。

## 3. 功能一：年代相册

### 3.1 核心流程（语音优先、大字、单步确认）

1. 老人拍一张"现在"的照片（现在的老家 / 老物件 / 现在的自己等），想发朋友圈，先把照片发到小程序聊天里。
2. 小辽引导口述：这张照片是什么？以前是什么样子的？（今昔对比）
3. 小辽根据描述检索"过去模样"的示意图（60 年代车间、老屋土房等），在聊天里发出来（角标"年代示意图"）。
4. 老人看图讲故事（可选），小辽引导式访谈：当时几岁 / 在哪 / 和谁 / 后来呢（一次只问一个问题）。
5. AI 润色故事（可选）：原文与润色版并排展示，老人可自由选用原文、润色版或中间版本。
6. 生成朋友圈文案：今昔对比式文案 + 图文卡片（老人照片 + 过去示意图 + 文案），一键复制或保存。
7. 一键分享给家人（企微 / 微信）。

### 3.2 配图逻辑（根据"以前是什么样子"的描述检索）

- 输入：老人发的"现在"照片（作为语境）+ 口头描述（这张图是什么、以前是什么样子、人物形象、服装、职业、场景、年代）。
- 输出：过去模样的示意图（**非老人照片，来自素材库/网络免费图**）。
- 检索维度：年代 × 人物形象（性别/年龄段/发型/服装）× 场景（工厂/军营/田野/火车站/全家福/结婚照等）。

### 3.3 素材库方案

- 主方案：本地预筛素材库。运营侧按标签体系（年代×人物×场景）预筛可商用、无水印图片，存入自有 OSS。
- 兜底：境外免费图源（Unsplash / Pexels / Openverse），注意大陆服务器访问限制，一律预下载到自有 OSS 后再展示（小程序图片域名有白名单限制）。
- 禁止：带水印、不可商用、来源不明图片。
- 可选增强（未来）：AI 按描述生成"想象里的你"（年代风画像），作为加分项而非主路径。

### 3.4 现在照片 vs 过去示意图（防记忆混淆）

- 老人拍的是"现在"，检索到的是"过去示意图"，两者在图文卡片上分别标注（现在 / 年代示意图），避免老人把网络图误认为自己的老照片。
- 示意图常驻角标"年代示意图"，真实照片与示意图在相册中分开展示。

### 3.5 AI 润色原则

- 不虚构事实：不编造日期、人名、地名。
- 只做通顺、分段、加标题、温柔补细节；拿不准时反问老人。
- 原文与润色版并排，老人可自由选择。

### 3.6 朋友圈文案生成（按老人意愿）

- 触发：老人拍照片发来、完成描述与配图后，小辽生成今昔对比式朋友圈文案（"以前是土房，现在是楼房"这类对比口吻）。
- 生成前问两个轻问题：发给谁看（老朋友 / 儿女家人 / 自己纪念）、什么风格（朴实 / 温暖 / 幽默 / 自豪）。
- 输出 2~3 条备选文案，每条 1~3 行，口语化长辈口吻；老人可一键选，或说"再改改"。
- 落地方式：
  1. 一键复制文字，老人自己贴到朋友圈；
  2. 生成图文卡片（文字印在配图上），保存图片直接发朋友圈；
  3. 完整故事放卡片第二张，朋友圈文案只做浓缩和钩子。
- 隐私与标注：涉及家人默认用"我家小孙女"式称呼，不暴露真名；图文卡片保留"年代示意图"角标。

## 4. 功能二：人生时光轴（以老人自己的一生为主线）

### 4.1 定义

- 以老人本人为轴心的一生地图，家人事件作为挂在这条线上的节点（如"女儿出生那年我 30 岁"、"抱孙子那年我 62 岁"）。
- 主轴：出生 → 上学 → 工作 → 结婚 → 生子 → 抱孙 → 退休 → 现在，按年代分章。

### 4.2 内容来源（按老人负担从小到大）

1. 相册故事自动抽取沉淀：写故事时标记人物/时间 → 建议生成时间轴节点，老人一键确认。
2. 引导式访谈：小辽主动发现时间轴空洞并提问（"1960~1970 这段还没有故事，要不要聊聊那几年？"）。
3. 子女代录：小程序里帮老人录入，老人只确认。
4. 模板占位：出生 / 上学 / 工作 / 结婚 / 生子 / 孙辈等大事件默认占位。

### 4.3 展示形态

- 年代章节式时间轴：大字、大图、可横向滑动，节点可点开看完整故事和照片。
- "那年我 X 岁"自动换算。
- 增值产物：AI 把一串故事串成给孙辈的家书 / 人生长图。

### 4.4 AI 角色

- 从故事中抽取时间 / 人物 / 事件（NER + 日期解析）。
- 自动发现时间轴空洞并生成提问。
- 生成旁白、家书、朋友圈文案。
- 照片年代识别（可选）。

### 4.5 隐私

- 家人与孙辈信息需授权；分享链接支持有效期与撤回；可见范围可设置。

## 5. 技术落地建议

### 5.1 模块划分

- `xiaoliao-api` 新增 `m4`（memory）包，沿用 M3 模式：Flyway 迁移脚本 + entity/mapper/service/controller。

### 5.2 表结构草图

- `m4_album`：相册（用户、主题、年代）。
- `m4_photo`：照片（来源 user_upload/stock、示意图标记、授权信息、年代标签）。
- `m4_story`：故事（原文、润色版、标题、年代、状态、关联照片）。
- `m4_moment_copy`：朋友圈文案（版本、风格、选中状态）。
- `m4_family_member`：家人（关系、生日、代际）。
- `m4_timeline_event`：时间轴节点（时间、类型、关联 story、关联人物）。

### 5.3 Python AI 引擎新增接口

- `/v1/story/polish`：故事润色。
- `/v1/story/extract`：抽取时间/人物/事件。
- `/v1/photo/search`：素材检索（本地库优先）。
- `/v1/story/interview`：引导提问。
- `/v1/moment/generate`：朋友圈文案生成。

### 5.4 复用现有模式

- 每日限额：Redis 分布式锁，仿 M3 三件好事 `DAILY_LIMIT` 模式。
- 耗时任务：丢 `xiaoliao-task` 异步执行（搜图缓存、长图/卡片生成）。
- 企微定时提醒："今天聊聊哪张照片？"。

### 5.5 成本与合规

- 成本点：AI 调用 + 图库检索。对策：每日限额 + 素材本地化缓存。
- 版权：只收录可商用图片，落库记录来源与授权。
- 隐私：家人信息授权、分享可撤回。
