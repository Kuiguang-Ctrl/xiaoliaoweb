# 小辽功能说明：年代相册 & 人生时光轴

## 功能一：年代相册（开放式动作）

**设计原则：不强制流程，老人点哪个做哪个**

1. **发照片**：老人拍一张现在的照片（老家/老物件/现在的自己），发到小程序聊天里，随便说一句也行（"这我老家""想发朋友圈"）。
   - 小辽：收到照片啦！您想做什么？
   - 弹出两个大按钮卡片："配一张当年的图" / "写朋友圈文案"
   - 老人点哪个做哪个，不点就不做，随时可以切回正常聊天。

2. **配一张当年的图（可选动作）**：老人说"以前是土房，墙都是泥的" → 小辽根据描述去素材库/网上搜一张相关示意图（带"年代示意图"角标）→ 老人说"像"就留下，"不像"就换个说法再搜，"不用图"就跳过。
   - 兜底：搜不到或老人不要图，就不配图，不影响后面。

3. **写朋友圈文案（可选动作）**：老人说"帮我写条朋友圈" → 小辽按今昔对比写 2~3 条备选（"以前是土房，现在是楼房……"）→ 老人选一条，或说"再改改"，或自己说一句让小辽润色。
   - 没有照片也能写：老人光说一段话也能生成文案。

4. **讲故事（可选动作）**：老人想讲就进入一问一答（一次只问一个问题），讲完 AI 润色；不想讲就不进。

5. **出图发朋友圈**：一键复制文字；或生成图文卡片（现在照片 + 过去示意图 + 文案），保存图片直接发朋友圈。

**关键设计点**
- 三个动作（配图/文案/故事）各自独立、顺序自由、可跳过，不做强状态机；
- 图是"示意图"不是本人照片，卡片常驻"年代示意图"角标；
- 老人全程不用打字，说"要/不要/再改改"就行；
- 随时可退出，不强迫完成。

## 功能二：人生时光轴

**老人完整操作流程（只有老人自己的用户端）**

1. **进入**：聊天里点"我的时光"卡片，或小辽问"要不要看看您的一生？"。

2. **看到全景**：一列纵向的时间轴，按人生阶段分章：
   - 出生与童年 → 上学 → 工作/当兵 → 结婚成家 → 生儿育女 → 孙辈 → 退休与现在；
   - 大字、大图、可上下滑动，每个阶段有代表性示意图；
   - 每阶段标注大致年代区间 + "那年我 X 岁"；
   - 每个节点显示：标题 + 一两句故事摘要。

3. **备选人生关键节点路径**：预设关键节点（上面那七个阶段），老人点开某个节点：
   - 上传照片 + 讲故事 → AI 润色文字 → 保存成节点内容。

4. **卡住时求助家人**：老人想不起这个节点的故事，或没有照片时，点节点上的"请家人帮忙"：
   - 生成分享（链接/卡片）发给子女或朋友；
   - 对方帮忙补一张照片或写一句提示；
   - 老人确认后挂到节点上（只针对单个节点求助，不是整体代录）。

5. **点开看详情**：点任意节点，看完整故事、配图，可以再听一遍（朗读）。

6. **补空白**：小辽发现某个阶段一个节点都没有，会主动提："您'工作'这段还没讲过，要不要聊聊？" → 老人开讲 → 新节点挂到对应阶段。

7. **阶段可增删**：老人说"我没上过学"就跳过；也可加自定义阶段（如"下乡"）。

8. **收尾产物（可选）**：故事攒得差不多，小辽生成"给孙辈的一封家书"或"人生长图"，分享给家人。

**关键设计点**
- 只有老人自己的用户端，不做子女代录入口；
- 主轴永远是老人自己的一生，按人生阶段分章，年代只做辅助标注；
- 内容靠聊天一问一答慢慢攒，不是让老人填表；
- 卡住（想不起故事/缺图）时靠"请家人帮忙"补单个节点；
- 最终产物是能传给家人的东西，给老人"留下点什么"的成就感。
