# 小辽「回忆视频」产品聚焦方案

> 定位：老年积极心理 AI 助手「小辽」的陪伴叙事功能 —— 把老人讲的一段人生回忆，做成一段可以反复回看、可以分享给家人的小视频。
> 归属：M4「回忆与传承」子功能，入口放在「人生时光」节点详情与「年代记忆」故事里。

---

## 1. 一句话产品定义

**老人上传 1–3 张照片，跟着小辽的引导用语音讲一段往事，小辽把照片、语音和文字整理成一段带背景音乐的回忆视频；老人满意就保存，愿意就一键分享给家人。**

## 2. 我们想带给老人的心理价值

- **被看见、被珍藏**：人生片段被整理成作品，而不是散落的照片。
- **积极重访**：回看时重新体验“那时候的幸福/成就感”，强化正向记忆（积极心理学中的怀旧疗法方向）。
- **被家人回应的机会**：一键分享 = 主动创造一次与子女孙辈的情感连接。
- **低负担、高掌控**：全程单步确认、随时可改，老人始终是内容的主人。

## 3. 核心流程（小辽全程引导，一次只问一步）

### 第 1 步：选照片（1–3 张）
- 小辽说：“咱们把这段做成一个小视频。您先挑 1–3 张那会儿的照片，一张也行。”
- 老人从节点已有照片里勾选，或现场新传。
- 前端即时预览所选顺序；顺序可拖。

### 第 2 步：按提示补充“关键信息”（不是开放式自由发挥）
- 小辽按照片内容逐条引导（每条老人只用语音答一两句）：
  1. 这是哪一年、在哪拍的？
  2. 照片里都有谁？和您是什么关系？
  3. 那天/那段时间您在做什么？
  4. 现在想起这段，心里是什么感觉？（情绪词引导：高兴 / 想念 / 骄傲 / 平静…）
- 老人用语音回答，ASR 转文字，小辽实时确认：“我记下啦：1985 年，厂里，和老同事们…”

### 第 3 步：小辽生成回忆视频
- 内容 = 照片轮播 + 关键信息整理成的旁白文字（小辽润色，口语化、不煽情、尊重原话）+ 老人原声（可选保留）+ 背景音乐。
- 生成期间页面显示进度与可等待提示；默认时长约 15–30 秒。

### 第 4 步：试看与修改（不满意可改）
- 老人先试看，可一键修改：
  - 换照片/调顺序；
  - 改旁白文字（也可语音说“把XX改成XX”）；
  - **换背景音乐**：自动匹配不满意时，可在线搜索按“温暖/轻快/怀念”等试听替换。
- 每次修改只重做对应部分，不推倒重来。

### 第 5 步：保存 / 一键分享
- 保存：存入“我的时光/花园”，可反复回看。
- 一键分享：生成带封面和标题的分享卡片；发给微信家人后，对方打开即看视频。
- 分享前默认征求老人同意，不给老人造成“被曝光”的压力。

## 4. 背景音乐策略

- **自动匹配**：依据关键信息中的年代/情绪关键词（温暖、怀念、轻快、舒缓…）自动选曲。
- **不满意 → 在线搜索**：按情绪/风格/关键词搜索试听，用户选定后仅重混音轨（快速重生成）。
- **来源与合规**：
  - 内置 3–5 首免版权演示曲（离线可跑，保证无网也能演示）；
  - 在线源接 Jamendo 等 CC/免版权曲库 API（需 client_id，可配置）；
  - 不做网易云/QQ 等无授权抓取。
- 音乐默认人声清晰优先：人声为主、BGM 低音量铺底。

## 5. 技术方案（当前仓库落地）

- **视频合成**：后端用 FFmpeg 本地合成（照片轮播 + 运镜 + 旁白/原声 + BGM 混音 → MP4）。
- **可插拔生成器**：`VideoGenerator` 接口。现实现 = 本地 FFmpeg；将来拿到图生视频 API（可灵/即梦/通义万相等）时新增实现即可替换，前端流程不变。
- **数据落库**：新增 `m4_video` 表（归属用户/节点或故事、照片 id 列表、旁白文字、原声音频地址、BGM 记录、成片地址、状态），重生成时保留记录复用素材。
- **网页版入口**：`web` 的节点/故事详情新增「🎬 生成回忆视频」；demo 版暂不做。
- **环境依赖**：本机需安装 FFmpeg（`brew install ffmpeg`）；当前 Mac 未装。

## 6. 交互原则（老年友好）

- 全流程语音优先、可打字；大字、单按钮、单步确认。
- 每步都有“返回上一步”；生成/修改期间可随时停下。
- 分享是“主动邀请”，不是自动公开。

## 7. 本次实施范围（建议顺序）

1. 后端：`m4_video` 建表 + 接口（创建/生成/换BGM重生成/查询/删除）+ FFmpeg 合成器 + 内置 BGM。
2. 网页版：节点/故事详情“生成回忆视频”入口 + 选照片 + 引导问答（AI 文字版）+ 试看/换 BGM/保存。
3. 分享：生成分享卡片/链接（复用现有“请家人帮忙”免登录模式）。
4. 语音引导的“听感”打磨：小辽引导语按人设卡口吻输出。
